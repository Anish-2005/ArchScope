# Contributing to ArchScope

First off, thank you for considering contributing to ArchScope! It's people like you that make ArchScope such a great tool for the engineering community.

## Code of Conduct

By participating in this project, you are expected to uphold our Code of Conduct. Please be respectful and professional in all interactions.

## How Can I Contribute?

### Reporting Bugs
- Use the GitHub Issue Tracker.
- Describe the bug and include steps to reproduce.
- Mention your OS and browser version.

### Suggesting Enhancements
- Open an issue with the "enhancement" label.
- Explain why this enhancement would be useful.

### Pull Requests
1. Fork the repo and create your branch from `main`.
2. Install dependencies: `npm install`.
3. If you've added code that should be tested, add tests.
4. If you've changed APIs, update the documentation.
5. Ensure the test suite passes: `npm run lint`.
6. Format your code: `npm run format` (if available).
7. Submit a pull request.

## Style Guide

- Use TypeScript for all new features.
- Follow the existing architectural patterns.
- Ensure all components are responsive and follow the design aesthetic (glassmorphism, dark mode).

## Future Roadmap

We are planning to expand ArchScope into:
- A Chrome Extension for real-time analysis on GitHub.com.
- Deep dependency graph visualization.
- Automated PR comments for architectural drift.

Happy coding!
